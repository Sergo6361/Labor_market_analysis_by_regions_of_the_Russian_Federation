«Сделать дашборд для службы занятости, которой нужно анализировать рынок труда по регионам РФ за последние несколько лет.

Что делал:

— Изучил исходные данные и провёл анализ количества пользователей и игровых сессий. — Рассчитал долю проблемных сессий по типам устройств и оценил соответствующие характеристики аномалий. — Определил коэффициент вирусности игр и средний размер будущих пользователей. — Проанализировал динамику доходов и влияние маркетинговой кампании на финансовые показатели. — Оценил изменения ключевых метрик DAU/WAU/MAU и их расположения. — Рассчитал долю лояльных пользователей, протестировав разные критерии определения лояльности.

Используемые инструменты: PostgreSQL (CASE WHEN, агрегации, JOIN-ы, CTE/подзапросы), Excel (постобработка, визуализация).

Результат: подготовлена ​​презентация с альтернативными выводами и визуализациями, демонстрирующая динамику пользовательской активности и влияющую на маркетинговые факторы на доход в игре».
